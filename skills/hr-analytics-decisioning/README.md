# HR Analytics Decisioning Skill

Companion to **people-science-core-reasoning**.

Focuses on translating people and HR questions into measurable variables, appropriate analytical designs, and actionable decisions.

## When to use

- Turning business or HR questions into metrics
- Designing people analytics studies or dashboards
- Interpreting workforce data, surveys, or predictive models
- Building or reviewing decision systems that use people data
- Evaluating the quality of existing HR metrics and analyses

## Relationship to Core Skill

Always apply the Core Reasoning sequence first.  
This skill adds the translation layer from question → construct → variable → design → decision.

## Installation

Place the `hr-analytics-decisioning/` folder alongside the other people-science skills, or install via:

```bash
npx skills add https://github.com/rewardsdna/people-science-skills --skill hr-analytics-decisioning
```
