# Organizational Behavior Decisioning Skill

Companion to **people-science-core-reasoning**.

Focuses on distinguishing mechanisms from assumptions, identifying behavioral explanations, and avoiding over-psychologizing of workplace phenomena.

## When to use

- Analyzing culture, engagement, motivation, or “soft” people issues
- Understanding resistance to change, teamwork problems, or leadership effectiveness
- Designing interventions intended to change workplace behavior
- Evaluating claims about psychological constructs in organizations
- Any situation where the risk of superficial or individualistic explanations is high

## Relationship to Core Skill

Always apply the Core Reasoning sequence first (Question → Behavior → First Principles → Evidence → …).  
This skill adds OB-specific distinctions, mechanism checklists, and guardrails against over-psychologizing.

## Installation

Place the `organizational-behavior-decisioning/` folder alongside the other people-science skills, or install via:

```bash
npx skills add https://github.com/YOUR-USERNAME/people-science-skills --skill organizational-behavior-decisioning
```
